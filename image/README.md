# 预编译固件（kid_buddy）

本目录存放**可直接烧录的整机固件**，用于在评委环境中复现作品，无需自行编译。

| 文件 | 说明 |
|---|---|
| `kid_buddy_gemini-s1_uart0_128Mnand_v2.67.img` | Gemini-S1（全志 R528）NAND 整机镜像，应用版本 `v2.67`（**最新，推荐烧录**） |
| `kid_buddy_gemini-s1_uart0_128Mnand_v2.67.img.sha256` | 上者的 SHA256 校验和 |

仓里只放**交付的这一份**。开发过程中的 `v2.60` ~ `v2.66` 七份历史镜像留在本地，
没有进仓——每份 27 MB，堆在仓库里除了让 clone 变慢没有别的用。

### 版本变更

- `v2.67`：字幕**改滚动**。v2.65/v2.66 的正文只显示两行，后面直接省略号截掉——
  而提示词要求模型答 100 字，两行 33 格只有 66 格，**大部分回复都断在半句，剩下的
  够不着**。改成：正文标签可以长到 8 行，前面开一个正好两行高的窗口，
  每 2.5 秒往上走一行，走到底再回到开头循环。孩子那句话的那一行不动。
  窗口是一个普通对象，LVGL 只按矩形裁剪子对象（`lv_refr.c` 里按父对象坐标取交集），
  所以窗口外的行是真的没画，不是被压扁。正文没变化 2.5 秒后才开始走，
  流式回复不会一边滚一边改字。
- `v2.66`：修字幕**换行**（v2.65 的字幕在模型回复里带换行时会溢出到第三行，
  多出来的那一行被标签裁掉，正文会**无声地断在半句**，连省略号都没有）。
  换行改由应用自己算：按字体实际宽度精确计格（8px 半角 / 16px 全角，并单独列出
  SimSun 里 128 个"小于 U+2000 但其实是全角"的字符 —— ° ± × ÷ 希腊字母、
  西里尔字母，这些按半角算会让一行宽 8px，恰好够 LVGL 再折一次行），
  逐字断行并写入 `\n`，超出两行的部分以省略号结尾。
  顺带修了孩子那一行被重复扣掉 4 格（「你：」前缀被算了两遍）。
- `v2.65`：**脸谱下方加回字幕** —— 底部三分之一是一块三行字幕板：第一行是
  孩子说的话（「你：」+ 语音识别结果），下面两行是模型回复正文。
  脸等比缩到上面三分之二，六个表情与全部道具照旧。
  字幕正文是为了**评委和旁观的大人**——孩子自己读不了，但语音链路一旦没出声，
  屏幕上的字是唯一能证明"它在工作"的东西。刷新做了节流（流式回复最快 250ms 一次，
  最终一定刷），避免每来一小段就刷一整屏、跟 TTS 抢 SPI。
- `v2.64`：**界面重做 —— 整屏换成一张纯几何的脸**（这一版起不再显示文字）。
  六个基础表情（平静/高兴/惊讶/专注/难过/困倦）配头顶道具
  （转圈的三点/随音量跳的弧/摇晃的铃铛/飘的泡泡），把 21 个设备状态映射成"看得懂的表情"；
  右缘四条书签带点一下切角色（也可用语音切）。全部用 LVGL 图元画，**不带任何美术素材**。
- `v2.63`：修首次开机屏幕上出现 `Sorry, I encountered an error.` 的问题 —— 没联网时
  不再发主动对话请求，且模型失败时改用本地中文安抚语，不再把英文报错显示/念给孩子。
- `v2.62`：修开机时把技能文件路径当成语音念出来的问题（技能摘要缓冲区越界）；
  开机先本地播一句欢迎语，再交给模型续讲上次的故事。
- `v2.61`：修「板子无 RTC → 时钟不可信 → 精准日期提醒算错」，未校时拒设绝对时间。
- `v2.60`：修 `CONFIG_LCD_FRAMEBUFFER` 导致的白屏（`/dev/lcd0` 不注册）。

## 镜像内容

- **应用主体**：本仓 `app/kid_buddy/`（LVGL 图形界面 + 语音交互 + 多角色文字 RPG）
- **上游依赖**：`packages_ai_agent` 的 4 个 PR 改动（#33 voice / #34 reminder / #35 rpg / #36 cli）
  在本镜像中**已编译进去**。这 4 个 PR 提交在 `open-vela/packages_ai_agent` 的
  `dev-ai-contest-2026` 分支上，评审合入前，直接按 `openvela.xml` 编译本仓会因缺少
  `velaclaw_ask_req_t.chat_id` / `velaclaw_publish()` / `velaclaw_set_notify_callback()`
  而链接失败 —— 本预编译镜像即为规避该依赖、保证可复现而提供。
- **板级改动**：本仓 `board/nsh_minidisplay/`（板级 defconfig + `Make.defs`）与
  `vendor/allwinnertech` 的 3 个文件（启动脚本 `rcS.nsh`、音频 codec 驱动、以及
  上游板级 defconfig），已随镜像生效。

## 烧录

镜像格式与全志官方整机包一致（`128Mnand` 分区布局），使用全志 PhoenixSuit / LiveSuit
按常规流程烧录：板子进入烧录（FEL）模式 → 选择本 `.img` → 烧录完成后重启。

启动后 `rcS.nsh` 会自动拉起 `kid_buddy`（图形界面）与 `ai_agent`（语音/对话后台）。

sha256sum -c kid_buddy_gemini-s1_uart0_128Mnand_v2.67.img.sha256
